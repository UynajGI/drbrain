# 平台路线图：通用科学平台

> 定位：四层核心（数据管线 / 检索 RAG / Model-as-Tools / 研究回路）**领域无关**；
> 领域知识全部经插件协议（[docs/plugins.md](plugins.md)）进入。材料学 A 线是第一个领域
> 插件包——它是核心的消费者与验收用例，不是核心的组成部分。
>
> 基线：2026-09-11，PR #64 合并后（schema v20，测试全量绿）。

## 四大倡议与验收标准

### 1. 插件系统规范化（地基，其余三条都依赖它）

| 阶段 | 内容 | 验收 |
|---|---|---|
| v1（现行） | ABI 版本协商（`abi_version` fail-closed）；协议文档 `docs/plugins.md` | 旧插件零改动可加载；新 ABI 被拒并告警 |
| v2 | manifest 化（元数据与代码分离）+ 符合性测试套件（插件作者可自跑） | research/plugins 全量通过 conformance suite |
| v3 | 权限/沙箱 profile 生效（`approval_policy` 接入研究回路实算门）；分发（git 插件包 + 锁定） | 领域插件无需宿主改动即可上线新工具 |

### 2. autoresearch 实算闭环（"有意义"的定义）

**验收：一次端到端成功运行的持久化记录**——文献检索 → 假设生成 → 领域插件真实计算
（非模拟）→ 数值验证门通过 → 结论沉淀进 claims，全程 ledger 可复放、证据可追溯。

- 第一轮用材料学 A 线（flatband/DFT）作为领域插件包跑通——它是验收用例
- 跑通后从运行记录里提炼"失败模式清单"，反哺讨论层与实算门
- 依赖：倡议 1 的 v2（实算插件的结算幂等需要 conformance 背书）

### 3. webui：单人版 → 产品

| 阶段 | 范围 | 验收 |
|---|---|---|
| v1 单人 | 本地 token 认证；会话/运行记录持久化；autoresearch 运行实时视图（ledger 事件流）；插件管理页（列表/启停/健康） | 单人完成"发起研究 → 观察闭环 → 导出结论"全程不碰终端 |
| v2 产品 | 多用户 + 部署包（容器化）+ 真前端框架迁移 | 非本机用户可注册使用，核心功能与 v1 对齐 |

### 4. 通用性验收（第二领域）

**验收：选一个非材料学领域（如电催化/电池/生物信息），只通过编写领域插件包 +
提供语料/评测集完成全流程接入，核心代码零改动。**

- 领域评测集由插件包提供（`rag/eval.py` 的内置问题集届时下放为材料学插件资产）
- 这是"四层统一通用"的可证伪检验；跑不通的差异点就是核心残留的领域耦合

## 依赖关系与推进顺序

> 优先级修订（2026-09-11）：**双主线并行 = 插件系统 + webui 设计开发**。
> autoresearch 的"有价值"是产品/研究验证问题，不是开发问题——开发侧只保证机制就绪
> （已完成），实算闭环的端到端验证推迟到插件/webui 主线稳定后，由研究侧发起。

新增工作项（2026-09-11 评审会）：
- **LLM 客户端迁移：litellm → OpenAI SDK**（litellm 缓存命中行为不可控）；波及
  `extractor/llm_client.py` 回退链与 webui 设置视图，迁移期间两条路径并行灰度。
- **RAG 记忆绑定层级落地**（项目 / 会话 / 实验三层作用域，默认会话、继承项目）——
  webui M1 的前置数据模型，见 [webui-design.md](webui-design.md) §4.1。

```
插件系统（v1 ✓ → v2 manifest+符合性套件 → v3 权限/分发）   ──┐
                                                          ├─ 并行双主线

        ↓ （主线稳定后，由研究侧发起）
autoresearch 实算闭环端到端验证（A 线作为第一个领域包）
        ↓
4. 通用性验收（第二领域）
```

## 已知非目标 / 暂缓

- autoresearch 端到端验证：机制就绪；价值验证属研究侧，非开发主线
- fastembed 嵌入/重排后端：接入点现成（provider 分发），待 rag_engine 双引擎裁决后再议
- rag_engine 双引擎（llamaindex vs sql）：需要 eval 数据裁决升现役或冻结
- 闭包规则覆盖率评估：闭环加固刚完成，暂无失败案例驱动
